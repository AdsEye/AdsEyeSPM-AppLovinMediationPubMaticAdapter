# AppLovinMediationPubMaticAdapter

AdsEye 维护的 Swift Package，来源版本 `5.0.1.0`。

在 Xcode 中添加 [本仓库](https://github.com/AdsEye/AdsEyeSPM-AppLovinMediationPubMaticAdapter)，选择 Exact Version `5.0.1-pod.0`，并将 `AppLovinMediationPubMaticAdapter` 添加到 App target。部署目标为 iOS 13 及以上。

App target 的 `Other Linker Flags` 加上 `$(inherited) -ObjC`。
